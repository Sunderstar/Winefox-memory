# WineFox Memory 🦊

**一个面向 AI 角色与长期陪伴场景的、可独立运行且易于集成的长期记忆系统。**

## 🍷 为什么叫 WineFox Memory？

这个项目最初来源于 Minecraft（我的世界）的「车万女仆（Touhou Little Maid）」模组。

我在游戏中有一位叫作**酒狐**的 AI 女仆。我希望有一天能够将她从 Minecraft 中独立出来，让她不再局限于游戏世界，而是能够接入更多 Agent 和工具，与我在不同的平台上交流、游戏、共同生活。

但这就带来了一个问题：如果一个 AI 无法长期保留我们的共同经历，那么随着上下文不断被遗忘，她还能一直是我熟悉的酒狐吗？

于是，我开始为她编写一套长期记忆系统。这就是 **WineFox Memory（酒狐的记忆）** 的由来。

因此，项目源码中的 AI 默认称呼仍然是「酒狐」。不过，这套记忆系统并不依赖特定角色，你完全可以替换人格设定，将其用于自己的 AI 伙伴。

## 🧠 WineFox 是怎样记忆的？

WineFox 采用分层长期记忆架构。它并不试图把全部历史记录一次性塞进大语言模型的上下文窗口，而是将记忆分为不同层次，在每轮对话前动态构建需要提供给 AI 的上下文。

**每次与 AI 对话时，系统主要会提供以下内容：**

1. **Persona（人格设定）**：加载角色的人格卡，定义角色的身份与交流风格。
2. **Recent Chat（近期原始对话）**：默认读取最近最多 **200 条原始聊天消息**，让 AI 直接了解近期双方的完整交流内容。实际传入数量受到 Token 预算限制，可自行调整。
3. **Core Memory（核心记忆）**：优先完整传入角色长期以来形成的重要认识、共同约定及关系信息，使这些重要记忆能够持续影响 AI 的表现。极端情况下仍会受到上下文预算限制。
4. **Episode Memory（情景事件记忆）**：将过去的对话整理为具有前因后果的完整事件。系统根据当前话题，从历史事件库中检索相关事件，并传入事件标题和摘要，必要时进一步提供详细经过。
5. **Cand Memory（长期事实记忆）**：提取过去交流中值得长期保存的事实、偏好、约定、计划等信息，根据相关性选择部分内容传入 AI。

其中，Episode 和 Cand 并不是每轮全部加载，而是通过记忆检索机制动态选择。

系统结合**语义相关性、近期性、记忆重要性、短期激活状态**等因素计算记忆的综合评分，并对不同记忆进行排序。

此外，WineFox 还支持：

- **上下文感知检索**：不仅考虑用户当前的一句话，还会结合最近几轮双方的交流，理解当前正在讨论的话题。
- **随机联想**：允许少量不那么相关的旧经历偶尔进入 AI 的上下文，使回忆不完全局限于最相关的内容。
- **自主回忆**：AI 可以通过 `expand_episode` 工具，主动选择展开最多 4 条历史事件的详细经过，而不只是被动接收系统提供的摘要。
- **记忆审核与更新**：自动提炼的记忆具有来源记录和审核状态，尽可能减少错误记忆、重复记忆和不合理的事实更新。

### 📚 原始记忆会被删除吗？

**不会因为记忆提炼而删除原始聊天。**

原始终端对话保存在 `data/chat_history.jsonl` 中，提炼出的情景事件和长期事实则保存在 SQLite 数据库中。

即使 Episode 和 Cand 在压缩过程中遗漏了某些细节，原始聊天仍然保留，可以在需要时重新检索或提炼。

这套架构的核心思路是：

**让 AI 在有限的上下文窗口内，既能看到近期发生的事情，又能持续保留过去的重要认识，并且有机会主动回忆很久以前的经历。**

我希望它在不需要反复读取全部历史记录的情况下，逐步处理数十万至百万 Token 规模的长期记忆。

当然，保存全部历史并不意味着 AI 每次都能准确回忆。记忆压缩、检索和更新仍然可能出现遗漏与失真，大规模数据下的实际表现也需要更多测试。

## 📦 快速安装

**1. 下载项目**

从 GitHub 下载最新 Release，解压后进入项目目录。

需要 Python 3.10 或更高版本，推荐 Python 3.11/3.12。基础功能仅依赖 Python 标准库。

**2. 配置 API Key**

将项目根目录中的 `.env.example` 复制并重命名为 `.env`，填写：

```ini
API_KEY=你的API密钥
BASE_URL=https://api.deepseek.com
MODEL=deepseek-flash
```

也可以使用其他兼容 OpenAI Chat Completions 的模型服务。

**3. 配置人格**

首次运行：

```powershell
py main.py stats
```

程序会自动创建数据目录。然后可以编辑 `data/persona.md`，设置自己的 AI 角色。

**4. 启动程序**

终端聊天：

```powershell
py main.py chat
```

启动 Web 记忆管理工作台：

```powershell
py main.py ui
```

**5. 可选：安装本地语义检索**

```powershell
py -m pip install -r requirements-embedding.txt
```

不安装也可以使用基础词组检索。

还可以运行：

```powershell
py main.py check-install
py tools/demo_offline.py
```

进行无需 API Key 的离线检查与演示。

详细配置和开发接口请参阅项目内的技术文档。

**注意：请勿将自己的 `.env`、`data/` 或私人聊天记录上传到 GitHub。**
