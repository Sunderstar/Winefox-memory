# Winefox-memory
一个面向 AI 角色与长期陪伴场景的、可独立运行且易于集成的长期记忆系统。WineFox Memory 使用分层记忆架构，将原始聊天、情景事件（Episode）、长期事实（Cand）与核心记忆（Core）分开管理。  系统支持自动记忆提炼、语义检索、上下文感知召回、记忆审核，以及由 AI 自主选择展开过去的事件详情。  项目使用 Python 开发，以 SQLite 和 JSONL 在本地保存记忆，提供独立终端聊天、Web 管理工作台和 Python 接口。  你可以直接将它作为带长期记忆的 AI 聊天程序使用，也可以通过 Python 接口将记忆能力集成到自己的 AI 角色或 Agent 项目中。
