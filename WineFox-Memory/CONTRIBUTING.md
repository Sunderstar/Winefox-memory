# 参与 WineFox Memory 测试与贡献

感谢帮忙测试！现在最有帮助的不是增加功能，而是让现有记忆工作流更稳定、可复现。

1. 按 README 在**你自己的**本地目录安装。初次测试推荐 `python tools/demo_offline.py`（不联网、不使用私人记录）。
2. 发现错误时运行 `python main.py diagnose`，检查输出 JSON，然后根据 `.github/ISSUE_TEMPLATE/` 选择程序问题或记忆表现问题。
3. 复现步骤尽可能短；用合成对话代替真实私人聊天，尤其注意模型原始输出和审查界面也可能包含私密内容。
4. 如想提交 PR，请同时提供新的合成回归测试，并运行 `python -m unittest discover -s tests -q`。
5. 不要在公开 Issue、PR、讨论区上传 API Key、`.env`、`data/`、个人聊天、人格、Core、原始日志、`.maid` 或数据库。

WineFox 不自动收集用户的数据，也不设置遥测服务器。问题反馈由使用者自行提交，可以只报告安装状态、版本与统计数量。请在分享前检查诊断文件，完全可以选择不提供。

当前优先接受：Windows 安装问题、UI 崩溃、数据库状态不一致、自动归档未触发、记忆提炼/召回可复现错误、隐私审计修复以及测试补充。
